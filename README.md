# p5.js Projects

A small collection of creative coding experiments built with p5.js. Each sketch explores motion, geometry, and generative visuals in a playful, experimental way.

## Included sketches

- Circling circles
  - A radial animation built from orbiting points, rotating axes, and layered circular motion.
- Cubes animation
  - A 3D grid of rotating boxes that responds to the mouse position.
- Hypnotic flowers
  - A blooming floral pattern generated with sinusoidal motion and layered petals.

## Getting started

1. Clone or download this repository.
2. Open one of the sketch files in a browser, or serve the project locally with a simple web server.
3. For example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- These are exploratory p5.js sketches designed for visual experimentation.
- The repository is intentionally lightweight and easy to extend.
- You can modify the sketches, adjust colors, animation speed, and geometry to create new variations.
